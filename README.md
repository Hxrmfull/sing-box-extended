# dist

Mirror of the latest `lean` release binary for routers that cannot reach GitHub release downloads.
Served through jsDelivr by install-lean.sh:
https://cdn.jsdelivr.net/gh/Hxrmfull/sing-box-extended@dist/sing-box-lean-linux-arm64.gz

`sing-box-lean-linux-arm64.sha256` is the checksum of the uncompressed binary.
Sources: branch `lean`.
